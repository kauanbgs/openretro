# OpenRetro v0.6.8

- Party: controles que o Windows não reconhece como padrão, como alguns de PS3 e controles USB genéricos, agora podem ser configurados pelo convidado. Aparece o botão "Configurar controle"; basta apertar cada botão pedido uma vez, e o mapeamento fica salvo no computador.
- Party: se a janela do jogo sair de dentro do OpenRetro durante a partida, ela volta para o lugar automaticamente.
- Os registros de cada partida ficaram mais completos, para diagnosticar jogos que não abrem.

Instale por cima da versão atual; biblioteca, configurações e saves continuam.
