# OpenRetro v0.6.2

- O idioma da interface acompanha automaticamente o idioma preferido do usuário: português para pt-BR, pt-PT e outras variantes de português; inglês para os demais idiomas.
- Nova opção **Automático (idioma do sistema)** nas configurações, mantendo a escolha manual de português ou inglês.
- O modo automático detecta novamente o idioma a cada inicialização, sem guardar uma detecção antiga como escolha manual.

Validação: 125 testes do aplicativo aprovados e build de produção concluído.
Esta atualização não exige migrações do banco nem publicação do Worker.
